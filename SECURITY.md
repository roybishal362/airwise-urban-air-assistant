# Security

## Reporting a vulnerability

Please open a private security advisory on this repository (GitHub → Security → Advisories → "Report a
vulnerability") instead of a public issue. We aim to respond within 72 hours.

## Threat model and controls

| Threat                                            | Control                                                                                                                                                                                                                                                                  | Where                                                                                            |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| Cross-site scripting via place names or AI output | All DOM text is written with `textContent`; no `innerHTML` anywhere; strict CSP (`default-src 'self'`, no inline script/style)                                                                                                                                           | `public/js/dom.js`, `src/http/middleware/security.ts`, XSS tests in `tests/frontend/dom.test.ts` |
| Prompt injection against the GenAI assistant      | User text is stripped of `<`/`>` and control characters, wrapped in `<question>`, and declared "data, not instructions" in a static system prompt; place names are restricted to place-name characters; the model only rephrases facts computed by deterministic engines | `src/services/assistant/prompt.ts`, `src/http/schemas.ts`                                        |
| Malformed or hostile input                        | Strict Zod schemas (unknown keys rejected, bounded strings and numbers), 16 KB body limit, JSON parse errors mapped to 400                                                                                                                                               | `src/http/schemas.ts`, `src/domain/household.ts`, `src/app.ts`                                   |
| Abuse and cost blow-ups                           | Per-IP rate limits (60/min API, 10/min GenAI chat), upstream timeouts, bounded retries, response caching with request coalescing                                                                                                                                         | `src/http/routes.ts`, `src/lib/http.ts`, `src/services/cache.ts`                                 |
| SSRF                                              | Upstream hosts are compile-time constants; user input only becomes URL-encoded query parameters                                                                                                                                                                          | `src/services/openMeteo.ts`                                                                      |
| Leaking internals                                 | Generic 500s, user-safe upstream messages; technical detail kept in server logs only; `x-powered-by` disabled                                                                                                                                                            | `src/http/middleware/errorHandler.ts`, `src/lib/errors.ts`                                       |
| Health-data privacy                               | No accounts or database; profile stored only in the browser; sent only in POST bodies (never URLs); responses `Cache-Control: no-store`; logs record method, path, status and latency only; coordinates rounded for cache keys                                           | `src/http/routes.ts`, `src/app.ts`, `public/js/storage.js`                                       |
| Secret leakage                                    | Keys only from environment variables; `.env` is git-ignored; config errors name the variable, never its value                                                                                                                                                            | `src/config.ts`, `.gitignore`                                                                    |
| Container hardening                               | Multi-stage build, production dependencies only, runs as the unprivileged `node` user                                                                                                                                                                                    | `Dockerfile`                                                                                     |
| Vulnerable dependencies                           | `npm audit --omit=dev --audit-level=high` runs in CI                                                                                                                                                                                                                     | `.github/workflows/ci.yml`                                                                       |
