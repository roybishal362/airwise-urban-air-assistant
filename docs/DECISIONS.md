# Design decisions and red-team log

This file records the key decisions behind AirWise and the hard questions each one had to survive. Where a question
exposed a real bug, the fix and the test that now guards it are named.

## 1. Architecture

| Decision                                                                     | Why                                                                                                                                                                                                               | Rejected alternative                                                                                                                             |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Deterministic domain engines compute every number; the LLM only explains** | Health and impact figures must be correct, reproducible and testable. An LLM is great at tailored language, unreliable at arithmetic.                                                                             | Letting the model estimate impacts directly.                                                                                                     |
| **One `AirBrief` object feeds the UI, the rule engine and the LLM**          | A single source of truth: the chat can never contradict the page.                                                                                                                                                 | Separate code paths for UI and chat.                                                                                                             |
| **Pure, I/O-free domain layer + dependency-injected services and UI**        | Every branch is unit-testable without network or browser; property-based fuzzing becomes possible.                                                                                                                | Fetching inside business logic.                                                                                                                  |
| **Vanilla ES modules, no front-end build**                                   | ~37 KB gzipped UI, nothing to compile, fewer supply-chain dependencies; type safety comes from `// @ts-check` against the server's own types.                                                                     | React/Vite: more weight than a seven-tab app of this size needs.                                                                                 |
| **Measured stations for "now", the CAMS model for the forecast**             | Stations (OpenAQ, free key) measure the real air; the model (Open-Meteo, no key) adds hourly forecasts and boundary-layer height. The forecast is rescaled to the measurement, and the source is always labelled. | Model only (it rated Delhi "Satisfactory" in late November); WAQI (returns AQI sub-indices, not concentrations, and its terms restrict caching). |

## 2. Red-team rounds

Each row is a question asked of the plan or the running app, the answer, and what changed.

| #   | Hard question                                                            | Finding                                                                                                                                                                                                | Resolution (and guard)                                                                                                                                                                                     |
| --- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | "Is the top commute suggestion actually safe on a smog day?"             | It recommended **cycling** (+786 % inhaled PM2.5) because ranking used CO₂ only.                                                                                                                       | Health-first ranking: options raising exposure > 25 % are "better on cleaner days" and never top. `compareCommute` tests.                                                                                  |
| 2   | "Does the headline say who the restriction is for?"                      | "Limit outdoor time for everyone" appeared when only the asthmatic member was at risk.                                                                                                                 | Headline names the sensitive group; healthy adults get a milder message. `assessFamilyRisk` tests.                                                                                                         |
| 3   | "Is the DIY filter figure honest?"                                       | 200 m³/h was optimistic for one filter on a table fan.                                                                                                                                                 | Conservative 150 m³/h, documented.                                                                                                                                                                         |
| 4   | "Does 'Before 07:00' mean today or tomorrow?"                            | Ambiguous for evening users.                                                                                                                                                                           | Day qualifiers everywhere ("tomorrow"). `dayQualifier` tests.                                                                                                                                              |
| 5   | "What if upstream blips?"                                                | A transient geocoding timeout surfaced to users, with the host name.                                                                                                                                   | One retry for transient errors; user-safe messages, details in logs only. `fetchJson` tests.                                                                                                               |
| 6   | "Will a redeploy serve stale JS against new HTML?"                       | Yes: JS/CSS were cached for a day without hashed names.                                                                                                                                                | ETag revalidation (cheap 304s) for HTML/JS/CSS. Integration test.                                                                                                                                          |
| 7   | "Can a 'city name' smuggle instructions into the prompt?"                | Place names reached the trusted `<air_brief>`.                                                                                                                                                         | Place names limited to place-name characters; system prompt treats them as data. API tests with injection-shaped names.                                                                                    |
| 8   | "Did we actually use GenAI, or only claim it?"                           | Live test: **every answer came from the rule fallback**: `gemini-flash-latest` does not exist and 2.5 models are closed to new keys.                                                                   | Ordered model chain (`gemini-3.5-flash-lite` → `gemini-3.8-flash`) with per-model deadlines; verified live in English and Hindi. Chain tests.                                                              |
| 9   | "Does the model get the units right?"                                    | Live test: it reported **52,000 kg** PM2.5 instead of 52,000 g, misreading `pm25GPerYear`.                                                                                                             | Quantities sent as unit-explicit strings ("52 kg PM2.5 per year"); test asserts no raw gram-coded fields reach the model.                                                                                  |
| 10  | "Is the emergency line noise?"                                           | It was appended to every answer, even CO₂ questions.                                                                                                                                                   | Only on health questions, using the local emergency number.                                                                                                                                                |
| 11  | "Are London and Delhi metro rides really equal in CO₂?"                  | Electric modes used India's grid factor everywhere.                                                                                                                                                    | Grid intensity per country; Indian schemes only in India. `region-policy` tests.                                                                                                                           |
| 12  | "Does this help Delhi families with the rules they actually live under?" | GRAP (school closures, car bans, WFH orders) was not modelled.                                                                                                                                         | GRAP stage from the NAQI, cumulative measures, and per-family implications. Tests per stage.                                                                                                               |
| 13  | "Do pale chart bars meet non-text contrast?"                             | Yellow-green/yellow levels were ~1.8:1 on white.                                                                                                                                                       | Bars get an edge in the text colour; contrast tests cover every theme token pair in light and dark mode.                                                                                                   |
| 14  | "Can another website spend our GenAI quota through visitors' browsers?"  | Possible: POSTs needed no cookie.                                                                                                                                                                      | Same-origin guard via `Origin` / `Sec-Fetch-Site`; 415 for non-JSON. Integration tests.                                                                                                                    |
| 15  | "Would Dependabot help?"                                                 | Its PR branches would break the single-branch rule.                                                                                                                                                    | Not enabled; `npm audit` + CodeQL instead.                                                                                                                                                                 |
| 16  | "Are the numbers real?"                                                  | User testing: the CAMS model alone showed **Delhi at NAQI 90, 'Satisfactory', on 24 Nov 2026**. It is a global model, and it under-reads South Asian winter smog.                                      | "Now" comes only from the nearest fresh reference monitors (OpenAQ); the forecast is rescaled per pollutant; the fallback is labelled with a warning on screen and in both assistants. `stations.test.ts`. |
| 17  | "Is it still a form with a report under it?"                             | Yes: one long page.                                                                                                                                                                                    | A tabbed app (Today, Forecast, My day, Home air, Impact, Family, Ask AI) using the WAI-ARIA tabs pattern, with deep links and a phone bottom bar. `tabs.test.ts`.                                          |
| 18  | "Does one slow station delay the plan?"                                  | Station readings were fetched one after another.                                                                                                                                                       | Parallel reads; a failing station is skipped; only an all-fail is reported (and logged). Concurrency test.                                                                                                 |
| 19  | "Are the station numbers in the right units?"                            | Live check (24 Nov 2026): OpenAQ labels CPCB gas sensors "ppb", but NOx = NO + NO₂ holds only if NO/NO₂ are µg/m³ (10 of 10 Delhi stations, within 0.3 ppb), and CO "0.87 ppb" is impossible outdoors. | CPCB gas readings are read in CPCB's native units (µg/m³, CO mg/m³); otherwise NO₂/SO₂ would be ~2× too high and CO ~1,000× too low. `effectiveUnits` tests use the live R K Puram values.                 |
| 20  | "Is official data fresh enough?"                                         | CPCB data reaches OpenAQ ~3.3 h after measurement, so a 3 h window rejected every CPCB station.                                                                                                        | 6 h window; the UI shows the measurement time range; calibration compares model and measurement at the measured hour, not "now".                                                                           |
| 21  | "What if someone imports their local .env into Vercel?"                  | It happened: `TRUST_PROXY_HOPS=0` came along, which would have put every visitor in one rate-limit bucket (60 requests a minute for the whole site).                                                   | The serverless entry pins trust to Vercel's fixed one hop; a test feeds it 0 and 2.                                                                                                                        |
| 22  | "Why did 'Use my location' fail with no explanation?"                    | Every failure showed the same message; on Windows PCs with Location services off the browser cannot locate at all.                                                                                     | A specific message per cause with how to fix it; a blocked permission is respected; otherwise the city-level area from the host's IP geolocation, marked "(approximate)". Tests per failure mode.          |
| 23  | "Is 31 requests for one page efficient?"                                 | No: 24 unbundled modules, each revalidated on every visit.                                                                                                                                             | esbuild production build: 3 hashed files, 26.5 KB gzipped, cached `immutable`; measured live: 8 requests on a first visit, JS/CSS from cache on repeat visits.                                             |
| 24  | "Does it reflow at 320 px?"                                              | Value columns were a fixed 4.5rem but never wrap, so "2,305 µg/m³" could spill out.                                                                                                                    | Value columns size to fit on small screens.                                                                                                                                                                |

## 3. Pre-mortem: "the submission scored poorly, why?"

| Possible cause                                     | Mitigation in place                                                                                                                                                              |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Judge can't run GenAI without a key                | Rule-based assistant answers from the same brief; README explains both modes.                                                                                                    |
| Judge or family doubts the numbers                 | "Now" comes from named official monitors with the measurement time on screen; every factor and source is in code comments and the README; property-based tests prove invariants. |
| Repository rules violated (size, branches, public) | 1 branch, well under 10 MB, no generated files committed, no bot branches.                                                                                                       |
| Accessibility claims untested                      | axe-core audits with a self-test, theme contrast tests, keyboard and focus tests.                                                                                                |
| Problem-statement drift                            | README maps every clause of the statement to code.                                                                                                                               |
